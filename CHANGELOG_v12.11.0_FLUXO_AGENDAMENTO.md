# v12.11.0 — Fluxo de agendamento corrigido

- Salvar link envia o registro para Agendamentos.
- Links de uma vez saem de Agendamentos após a execução.
- Sucesso sem erros -> Histórico de links enviados.
- Falha de envio ou imagem não encontrada -> Links com falha.
- Reenviar não depende mais do agendamento original existir.
- Editar falha cria novo agendamento e remove a falha após salvar.
- Validação de sintaxe do servidor e do JavaScript do painel concluída.
